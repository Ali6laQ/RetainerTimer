# Retainer Timer 🦷⏰

A simple and clean web application that helps calculate the exact time when I can remove my dental retainer after wearing it for 8 hours.

## About the Project

I created this project to make it easier to track my retainer wearing time.  
Instead of calculating the time manually, the app lets the user enter the time they put on the retainer and instantly shows the time when it can be removed.

The app adds **8 hours** to the selected starting time and displays the result in a user-friendly 12-hour AM/PM format.

## Features

- Simple and minimal design
- Easy-to-use time input
- Automatic 8-hour calculation
- Displays result in AM/PM format
- Responsive centered layout

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` → Main webpage structure
- `style.css` → Styling and layout
- `script.js` → Time calculation logic

## How It Works

1. Enter the time when you put on your retainer.
2. Click the **Calculate Time** button.
3. The app calculates 8 hours later.
4. The result shows the time when you can remove the retainer.

## Example

If you put on your retainer at:

```text
2:30 PM
```

The app will display:

```text
10:30 PM
```
